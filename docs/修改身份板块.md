# 修改指南：个人身份板块

> 这份指南教你自己动手改首页「Identity · 个人身份」板块的文字内容。
> 全程只需要改**一个文件**，改完保存就能在浏览器里看到效果。

---

## 一、打开这个文件

```
src/components/Identity.astro
```

用任何编辑器（VS Code、Cursor、文本编辑都行）打开。整个板块的内容集中在这个文件的 **前 30 行**。

---

## 二、三处纯文字（直接改引号里的字）

```astro
<p class="panel-eyebrow reveal"><Emblem size={14} /> Identity · 个人身份</p>   ← ① 板块小眉标
<h2 class="panel-title reveal" style="--d:1">你好，我是 Loky</h2>              ← ② 大标题
<p class="panel-desc reveal" style="--d:2">白天写 Objective-C，晚上研究底层，像磨刀一样磨自己。</p>  ← ③ 一句话介绍
```

想改哪句就改哪句，**只动中文/英文文字本身，别动标签和 class**。
（`Emblem size={14}` 是标题前的小纹章图标，别删。）

---

## 三、四张卡片（就是一个数组）

板块里的 4 张卡对应开头的一段数组，每张卡三样东西：`no` 编号、`title` 标题、`text` 描述：

```astro
const cards = [
  {
    no: '01',
    title: 'iOS 开发者',
    text: 'Objective-C / Objective-C++ 主力，把界面打磨到像素级。',
  },
  {
    no: '02',
    title: '底层与原理',
    text: 'Runtime、内存管理、渲染管线——知其所以然。',
  },
  // ... 03、04 同理
];
```

### 改文字
直接替换引号里的内容即可。引号用单引号 `'...'` 或双引号都行，**前后要配对**。

### 加一张卡片
在数组末尾照葫芦画瓢加一项（注意上一项末尾要有逗号）：

```astro
  {
    no: '05',
    title: '新方向',
    text: '正在琢磨的新东西。',
  },
];
```

### 删一张卡片
把对应的 `{ ... },` 整块删掉即可（注意别把数组的 `];` 删了）。

> **布局小贴士**：卡片是 2 列排列，4 张刚好 2×2；改成 3 或 5 张也能正常显示（会自动换行），但 4 张最齐整。编号只是装饰文字，`01`→`A` 也能显示，不过建议保持两位数字格式。

## 四、改完怎么看效果

开发服务器如果还开着（平时我给你留着，端口 4321），**保存文件后浏览器会自动刷新**：

## 六、⚠️ 别动的地方

| 位置 | 原因 |
|---|---|
| `import EvaAssembly from './EvaAssembly.astro'` 和 `<EvaAssembly />` | 右侧 EVA-01 组装机甲，删了机甲就没了 |
| 文件底部 `<style>` 整段 | 布局样式（左文右机甲双栏），改了排版会乱 |
| 每个元素上的 `class="reveal"` 和 `style="--d:N"` | 入场动画标记；`--d` 数字是出现顺序（越大越晚），调顺序可以改数字，删了就没有浮现动画 |
| `<section id="identity">` 的 id | 左侧刻度导航靠它定位，改了导航会失灵 |

---

## 七、报错了怎么办

最常见的报错是数组里**少了逗号或引号没配对**，浏览器会白屏并在终端显示类似：

```
Expected ',' ...  (7:12)
```

冒号前的数字就是出错的行号，回去看那一行，九成是标点问题。改不下去随时把报错贴给 ZCode。
